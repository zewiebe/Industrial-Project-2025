# Industrial Project 2025
## Our Goal
- Our goal is to create a functional prototype for a new contract tracker for the  steinbach hatchery
- Implement both some HCI methods in designing UI and some form of predictive aid
- create something that can demonstrate what steinbach hatchery is looking for while also bolstering our skills and resume
## Development 
- This project is being developed by the 3 of us as a part of the university industrial project program
- its being built in C# using visual studio and sqlite database
- there is no classtime or instruction we are building it on our own in our free time while consulting with steinbach hatchery
